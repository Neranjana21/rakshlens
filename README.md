# RakshaLens

An explainable scam-risk profiler for investment messages (WhatsApp/Telegram tips, "SEBI-approved" groups, recovery agents). Paste, upload a screenshot, or speak. It answers in English, Tamil or Hindi with a risk band, the exact phrases that triggered it, what it could **not** verify, and safe next steps (1930, cybercrime.gov.in, SEBI SCORES). It never gives stock tips or buy/sell advice.

SANGYAN Investor Resilience Hackathon, Track A: Digital Fraud & Scam Resilience.

> **Read `docs/evaluation.md`.** On messages the rules had never seen, about half of the scam messages were flagged High/Critical on the first run. Low means "no strong warning signs found", never "safe".

## Run locally
```bash
cd backend
pip install -r requirements.txt -r requirements-dev.txt
# optional, for screenshot OCR: install tesseract with eng, tam, hin language packs
uvicorn app.main:app --port 8000        # open http://localhost:8000
python -m pytest -q                      # 256 tests
python ../scripts/eval.py                # labelled-set results
```

## Deploy (Render, free tier works)
1. Push this folder to a GitHub repo.
2. Render → New → **Blueprint** → pick the repo. It reads `render.yaml` and builds the `Dockerfile` (includes Tesseract English/Tamil/Hindi).
3. Optional: set `ANTHROPIC_API_KEY` for opt-in cloud OCR and smoother summary wording. Without it everything still works with local OCR and vetted templates.
4. Open the URL, then check `/api/health`. The free tier sleeps when idle: open it once before the demo.

Env vars: `ANTHROPIC_API_KEY` (optional), `RAKSHALENS_MODEL` (default `claude-haiku-4-5-20251001`), `IVR_TOKEN` (generated by the blueprint), `RAKSHALENS_RATE_LIMIT` (default 30/min), `RAKSHALENS_MAX_UPLOAD_MB` (default 6).

## API
`GET /api/health` · `GET /api/config` · `POST /api/analyze` (multipart: `text`, `lang`, `allow_cloud`, `image`) · `POST /api/analyze/text` (JSON) · `POST /api/report` (printable masked evidence report) · `POST /api/ivr/{start,lang,result}` (TwiML).

## Front ends
- **Web app / PWA** (`web/`): installable, supports Share Target (share a message to it from the phone's share sheet once installed).
- **Chrome extension** (`extension/`): chrome://extensions → Developer mode → Load unpacked. Right-click selected text → check. Set your server address under the popup's settings (default `http://localhost:8000`).
- **Phone-call prototype** (`backend/app/api/ivr.py`): point a Twilio-style number's voice webhook at `/api/ivr/start?token=<IVR_TOKEN>`. Tested with simulated requests only. To demo it without a phone, open `/call.html` (the call simulator; on a server that has `IVR_TOKEN` set, such as the Render deployment, open `/call.html?token=<IVR_TOKEN>`, with the value from the Render dashboard; the token is hidden in what the page displays): it plays a call against the real endpoints, speaks the replies with the browser's voices, and shows each request.

## Privacy
Nothing is stored; no content logs; phones, UPI IDs and account numbers are masked in outputs and reports; no accounts or cookies. Cloud AI is used only if the user ticks consent and the server has a key.

## Verification status
Checked locally: the Docker image builds and runs, `/api/health` answers, the Tesseract Tamil/Hindi packs are present, and the drawn sample screenshots in `web/samples/` are read correctly in all three languages.

Not yet verified: a live deployment (the free Render host sleeps when idle, so open it once before a demo), real phone screenshots (dark mode, compression and wallpapers make OCR harder than the drawn samples), the Tamil speaker and voice input on real phones (voices depend on the device), and review of the Tamil and Hindi wording by native speakers.

## Known limitations
See `docs/evaluation.md`. Keyword/pattern coverage is the main weakness: on messages written after the rules, about half of the scams reached High/Critical on the first run. The app's guess of which app a message came from (WhatsApp, Telegram...) is a guess from a few clues, and it says "could not tell" when unsure. The Docker image runs locally but is not deployed yet. There is no mobile app in this repository.
